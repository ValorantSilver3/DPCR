# Dual-Attention Parallel Contrastive Reconstruction Network

## Dependences:
1.  Pytorch 1.8.0
2.  Python 3.7
3.  CUDA 11.3

## Main Characteristics:
1、It adopts channel attention and spatial attention mechanisms.

2、Combined with the atmospheric scattering model.

## Performance Metrics:
PSNR

SSIM

## Reasons for choosing the dual attention and atmospheric scattering model architecture
1、By focusing on information between channels and information in specific spatial regions, the network’s ability to extract global and local features is enhanced.  This effectively addresses the problem of uneven fog distribution and improves the feature extraction capability and generalization ability of the network model.

2、The atmospheric scattering model constructs a contrastive reconstruction constraint by using the generated clear images and the input hazy images. It avoids the problem of unstable learning of the generator caused by redundant data, and supplements the clarity of images as well as the content constraints of the network. This enhances the network’s reconstruction ability and dehazing performance.

3、Combining the two can achieve the complementary advantages of physical priors and feature learning. Ensure that the reconstruction results conform to the real imaging rules and avoid distortion or artifacts generated by the network. Effectively deal with the problem of uneven fog distribution and enhance the ability to extract global and local details. The dehazing performance and generalization ability of the model are improved.
